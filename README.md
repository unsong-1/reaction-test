# ⚡ 반응 테스트 멀티 플랫폼 (Reaction Test Suite)

모던하고 정밀한 UI/UX와 오차 없는 Web Audio API 타이머 시스템을 갖춘 웹 기반 **6종 멀티 반응 테스트 플랫폼**입니다.  
각 테스트의 **[준비 단계 (선택지 프리뷰)] -> [무작위 대기 단계] -> [목표 자극 제시 및 측정 단계]** 흐름을 명확히 분리하여, 예측 클릭 방지와 정밀한 밀리초(`ms`) 측정을 제공합니다.

---

## 🎮 6가지 반응 테스트 모드 (Multi-mode)

| 모드 | 이름 | 준비/대기 단계 (Preview & Wait) | 측정 단계 (Stimulus & Measurement) |
| :--- | :--- | :--- | :--- |
| ⚡ **초록불 반응** (`green-light`) | 클래식 반응 | 빨간색 대기 화면 ("초록색을 기다리세요...") | 화면이 즉시 초록색으로 전환되는 순간 클릭/Spacebar ms 측정 |
| 🎨 **색상 구분** (`color-match`) | 선택 반응 | 4개 색상 버튼이 미리 노출되어 위치 인지 가능 (상단 목표 대기) | 상단에 목표 색상(예: "파랑")이 제시되는 순간부터 일치하는 버튼 터치 ms 측정 |
| 🧭 **방향 반응** (`direction`) | 방향 인지 | 상하좌우 화살표 가이드 및 D-패드 미리 노출 (중앙 목표 대기) | 중앙에 목표 화살표(↑, ↓, ←, →)가 제시되는 순간 방향키 또는 D-패드 입력 ms 측정 |
| 🎯 **위치 조준** (`position`) | 타겟 에임 | **완전한 검은색 대기 화면 (Black Screen)** 유지 (예고 신호/텍스트 일절 없음) | 무작위 대기 종료 즉시 화면 내 무작위 좌표에 타겟 원이 생성되는 순간 클릭 ms 측정 |
| 🔷 **도형 반응** (`shape`) | 도형 인지 | 4개 도형 버튼(원, 사각형, 삼각형, 별) 미리 노출 (상단 목표 대기) | 상단에 목표 도형이 제시되는 순간 일치하는 도형 버튼 터치 ms 측정 |
| 🔔 **소리 반응** (`audio`) | 청각 반응 | 사전 안내 화면에서 **[목표 소리 들어보기]** 청취 가능 / 대기 중 **완전한 검은 화면 유지** | **화면 변화/시각 신호 없이** 목표 소리가 울리는 순간 즉시 클릭/Spacebar ms 측정 |

## 🚀 주요 개선 사항

### 1. 준비 단계와 실제 측정 단계의 명확한 분리
* **선택지 사전 인지 (색상 / 방향 / 도형)**: 테스트 시작 전부터 선택지 버튼들이 화면에 미리 배치되어 사용자가 위치를 사전에 인지할 수 있습니다.
* **조기 입력(False Start) 감지**: 대기 단계에서 목표가 나오기 전에 미리 누르면 조기 클릭으로 감지하여 실패 처리 및 재도전 기회를 제공합니다.
* **오답(Incorrect Answer) 분리 감지**: 선택형 테스트에서 목표와 다른 색상/방향/도형을 누르면 오답으로 처리하여 정답률 통계에 정확히 반영합니다.

### 2. 위치 반응 테스트 (Position Click) 검은 화면 최적화
* 타겟이 나타나기 전까지는 안내 문구, 로더, 예고 신호가 일절 없는 **완전한 검은색 대기 화면(Black Screen)**을 유지합니다.
* 타겟 생성 전 화면을 클릭하면 즉시 조기 클릭으로 처리됩니다.

### 3. 소리 반응 테스트 (Audio Reaction) 정밀 오디오 엔진
* **사전 청취 기능 (공통 오디오 엔진)**: IDLE 화면에서 실제 측정과 100% 동일한 목표 소리(880Hz 삼각형 파형, 250ms)를 단일 공통 함수(`playTargetSound()`)로 재생합니다.
* **빠른 연타 소리 겹침 방지**: 사전 청취 버튼을 빠르게 연타하더라도 기존 노드를 즉시 `stop/reset`하여 소리 왜곡이나 겹침 없이 맑은 톤을 반복 청취할 수 있습니다.
* **오토플레이 제한 해결**: [소리 들어보기] 및 [테스트 시작] 사용자 제스처 이벤트에서 `AudioContext.resume()`을 즉시 활성화하여 브라우저 정책 차단을 방지하며, 예외 발생 시 에러 로깅 및 안내 팝업을 제공합니다.
* **시각 신호 완전 제거**: 목표 소리가 재생되는 순간 화면에 색상 변화나 텍스트 알림 등 어떠한 시각적 힌트도 표시하지 않으며, **오직 100% 청각 자극**에만 의존하여 측정합니다.
* **출력 시점 정밀 동기화**: Web Audio API 오실레이터가 시작되는 정확한 타임스탬프(`exactStartTime`)를 기반으로 밀리초 오차 없이 반응시간을 측정합니다.

### 4. 테스트 회차 사이 전환 화면 (Intermission / Next Step Screen)
* **단계별 쿨다운 및 피드백**: 각 문제(회차) 측정이 완료되면 다음 문제로 자동 진행되지 않고, 중간 전환 화면에 머무릅니다.
* **상세 정보 표시**: 직전 회차 반응속도(`ms`), 정답/오답/조기반응 판정 배지, 맞춤형 평가 코멘트가 제공됩니다.
* **사용자 주도 진행**: 사용자가 화면의 **[다음 문제로 (라운드 X/N)]** 버튼을 직접 클릭하거나 `Spacebar`를 눌러야만 다음 회차의 무작위 대기 타이머가 시작됩니다.
* **마지막 회차 안내**: 세션의 마지막 회차 완료 시에는 [다음으로] 버튼 대신 **[최종 결과 확인하기]** 버튼으로 자동 전환되어 결과 대시보드로 안전하게 이동합니다.

## 💻 실행 방법

### 방법 1. 브라우저에서 직접 열기
- `reaction-time-test/index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등 모던 웹 브라우저에서 바로 실행할 수 있습니다.

### 방법 2. 로컬 웹 서버로 열기 (추천)
```bash
# Python 3
python -m http.server 8080

# 또는 npx serve
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속하여 6가지 모드를 모두 테스트할 수 있습니다.
